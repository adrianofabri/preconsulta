# Pré-consulta · Dr. Adriano Fabri Domingues

Página pública do formulário de pré-consulta (aberta pelo link enviado ao paciente: `?t=<token>`).

- A página só exibe o formulário; as respostas são enviadas ao Apps Script "Pré-Consulta – Paciente" (planilha no Google Drive do consultório).
- Nenhum dado de paciente fica guardado neste repositório.
- Hospedada fora do Google para evitar o erro do Google quando o celular tem várias contas conectadas.
